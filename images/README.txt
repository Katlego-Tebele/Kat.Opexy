==============================================================
  EPOXY FLOORING WEBSITE — IMAGE FILES REQUIRED
==============================================================

Place the following image files in this folder (images/):

--------------------------------------------------------------
  LOGO
--------------------------------------------------------------
  logo.png  — Company logo (PNG with transparent background)
              Recommended size: 200×60px or similar wide format
              A temporary SVG logo (logo.svg) is included as
              a stand-in. Replace it by adding logo.png.

  NOTE: The HTML references "images/logo.png". If you want to
        use the SVG instead, update index.html to reference
        "images/logo.svg" in the three logo <img> tags.

--------------------------------------------------------------
  HERO IMAGE
--------------------------------------------------------------
  hero.jpg  — Main hero background photograph
              Recommended: 1920×1080px or larger, landscape
              Subject: premium interior with glossy epoxy floor
              (marble-style, white/grey/blue flowing patterns)

--------------------------------------------------------------
  GALLERY IMAGES (10 required)
--------------------------------------------------------------
  gallery-1.jpg   — Flooring Project 1
  gallery-2.jpg   — Flooring Project 2
  gallery-3.jpg   — Flooring Project 3  (also used in About section)
  gallery-4.jpg   — Flooring Project 4
  gallery-5.jpg   — Flooring Project 5
  gallery-6.jpg   — Flooring Project 6  (also used in Showcase section)
  gallery-7.jpg   — Flooring Project 7
  gallery-8.jpg   — Flooring Project 8
  gallery-9.jpg   — Flooring Project 9  (also used in Showcase section)
  gallery-10.jpg  — Flooring Project 10

  Recommended size: 1200×900px or larger (landscape or portrait)
  Format: JPG, optimised for web (aim for under 300KB each)

--------------------------------------------------------------
  TIPS FOR BEST RESULTS
--------------------------------------------------------------
  • Use high-quality photographs showing the finished epoxy floor
  • Ensure floors are clean, well-lit and in focus
  • Landscape orientation works best for the gallery grid
  • Portrait orientation also works — the CSS handles both
  • Compress images using tools like:
      - https://squoosh.app
      - https://tinypng.com
      - https://imageoptim.com

--------------------------------------------------------------
  PLACEHOLDERS
--------------------------------------------------------------
  While your real images are not yet added, the website will
  display an attractive blue gradient placeholder instead of
  broken images — this is handled automatically by main.js.
